# Security policy

## Supported versions

Only the latest release receives security fixes, as a new patch release. Published releases never change.

tessera has no release yet. Until the first one, fixes land on `main`.

## Reporting a vulnerability

Report a vulnerability privately, with GitHub Security Advisories. Do not open a public issue, a pull request or a discussion for it.

1. Open the **Security** tab of <https://github.com/gtriggiano/tessera>.
2. Select **Report a vulnerability**, or go directly to <https://github.com/gtriggiano/tessera/security/advisories/new>.
3. Describe the problem: what an attacker can do, the steps to reproduce it, and the output of `tessera version`. Include the relevant part of the configuration, with secrets removed.

Only you and the maintainers can read the report. Never include real credentials, hostnames or addresses: use `example.com` and the documentation address ranges.

For any other problem, open an [issue](https://github.com/gtriggiano/tessera/issues/new/choose).
